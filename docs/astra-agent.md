# 星澪学习智能体

星澪是温柔、具体、克制的学习搭档。全部外观共用人格，对话页随成长装备显示。首页、题目、知识、比赛和报告入口可打开 `/companion`，携带对应上下文；原有 AI 按钮及结构化结果继续保留。

## 运行架构

- `shared/astra-model.ts` 统一人格与 OpenAI 兼容模型适配；复用设置中的地址、密钥和模型。固定任务调用同一适配层，不递归启动智能体。
- `shared/agent-service.ts` 使用 LangChain `createAgent` 与 LangGraph 状态、工具和事件流。查询、知识检索、代码分析、提示、诊断、经验卡草稿、对拍材料、迁移、训练计划、比赛及月报任务调用现有业务服务。
- 本地 Fastify 通过 POST 流式 NDJSON 返回事件；Pages 直接消费共享异步事件流。浏览器工具使用显式 `ToolRuntime.writer`，不依赖 Node 的 AsyncLocalStorage。
- 同一会话串行执行，工具依次运行；最多六轮模型调用、十二次工具调用，总运行期限三分钟。工具重复参数及请求编号去重；停止、账号切换、备份恢复会取消未完成运行。
- 文本、工具开始/结束、待确认操作、完成、失败均使用统一事件。界面只显示执行摘要和来源，不保存或展示模型内部推理。

## 权限与学习证据

查询、分析和新增 AI 草稿自动执行。覆盖复盘、删除内容、确认经验卡、变更训练目标、安排迁移必须展示具体前后变化，确认后再次检查账号、XCPC 身份和数据版本。重复确认返回原执行结果。未来题单沿用现有自动调整开关；关闭时仅生成方案，开启时也只调整未来日期，保留版本和撤回。

星澪不能填写独立重做评价、宣称用户 AC、修改经验或掌握度。题目解答、代码帮助及渐进提示写入现有提示记录；普通进度询问不计提示。引用和结构化任务继续沿用知识检索及学习服务的校验。工具结果属于学习数据，不能改写系统权限。

## ReAct 引导复盘与学习规划

题目、比赛及伙伴页面支持六阶段复盘：定位 → 回忆 → 调查 → 验证 → 整理 → 迁移。模型每轮先读取当前学习上下文，再按需调用工具，读取实际工具结果后提交检查点；用户回答或跳过后才进入下一轮。公开界面记录问题、证据、假设、动作与结果摘要，不展示模型内部推理，也不把 AI 判断计作独立掌握。

工作流保存账号、会话、题目或比赛上下文、阶段、版本、证据指纹和关联提案。刷新后可恢复；停止、账号变化和备份恢复使旧响应失效。读证据工具没有运行时不能提交验证检查点，六轮模型、十二次工具调用及三分钟期限与普通伙伴对话共用。提案仍需用户确认，工具只能读取已有训练记录或准备可审核的改动。

训练计划通过共享规划服务生成：BKT 仅吸收有效且可归属的练习观察，先修图生成学习路径，预算优化器选择未来任务。`planning_preview` 工具返回预算、估时依据、排除原因和版本；确认后应用，可精确撤回。自动调整只在用户显式开启时作用于未来日期，不改当天题单。默认 BKT 参数尚未用个人数据校准，样本不足显示不足；功能验证不等于学习效果验证，详见 [工作台说明](workbench.md)。

## 会话、记忆和备份

会话与长期记忆按当前 CF、AtCoder 账号组合隔离；XCPC 比赛会话额外校验选手身份。实时成绩和掌握度从学习记录读取。长期记忆默认开启，仅自动记录用户明确表达的目标、讲解偏好和习惯；不记录模型推测，敏感密钥表达不作为记忆。对话页可编辑、删除记忆或关闭记忆功能。

主动建议默认关闭，用户开启后仅在应用打开、首页或训练证据更新时检查；每个账号组合北京时间每天最多两次，忽略后不重复分析同一证据。

数据沿用现有存储层，本地 SQLite 与浏览器 IndexedDB 均可离线读取。备份版本为 11（兼容 v1–v11），包含会话、消息、运行、提案、记忆、设置、规划决策和引导复盘流程。旧版本学习记录无需迁移；恢复时未执行提案及规划预览失效，未完成运行取消、进行中的复盘流程标记为中断，继续前重新检查证据。密钥沿用现有配置和备份处理；没有新增数据库或云端追踪，LangSmith 自动追踪显式禁用。

## API

本地路径加 `/api` 前缀，Pages 提供同等适配。

| 路径                                | 方法         | 用途                     |
| ----------------------------------- | ------------ | ------------------------ |
| `/agent/review/start`               | POST         | 为已有会话开始引导复盘   |
| `/agent/review/session?sessionId=…` | GET          | 读取会话最近的复盘流程   |
| `/agent/review/:id`                 | GET          | 读取流程与中断状态       |
| `/agent/review/:id/respond`         | POST         | 提交回答或跳过，校验版本 |
| `/agent/review/:id/cancel`          | POST         | 停止运行并取消流程       |
| `/agent/sessions`                   | GET / POST   | 会话列表、新建会话       |
| `/agent/history?sessionId=…`        | GET          | 消息及操作历史           |
| `/agent/run`                        | POST         | 启动运行并消费事件流     |
| `/agent/runs`                       | GET          | 查询运行记录             |
| `/agent/cancel`                     | POST         | 停止会话运行             |
| `/agent/decision`                   | POST         | 确认或拒绝操作           |
| `/agent/session`                    | DELETE       | 删除会话及所属记录       |
| `/agent/memories`                   | GET          | 查看记忆                 |
| `/agent/memory`                     | PUT / DELETE | 编辑或删除记忆           |
| `/agent/settings`                   | GET / PUT    | 记忆与主动建议开关       |
| `/agent/suggestion`                 | POST         | 检查主动建议             |
| `/agent/dismiss`                    | POST         | 忽略建议                 |
| `/ai/capabilities`                  | POST         | 测试模型工具调用能力     |

不支持工具调用的模型仍可使用原有受控结构化任务，能力测试明确提示不能自由编排工具。模型断网或失败时保留已完成结果，聊天可重试；离线可查看已有会话、记忆和学习数据。

## 验证

自动测试使用模拟 OpenAI 兼容模型，覆盖真正的 LangChain 工具循环与流式响应，不上传学习数据。执行 `npm run check`、`npm test`、`npm run build`、`npm run build:pages`、`npm run test:e2e` 和 `npm run test:pages`。浏览器检查包括 390px / 1440px、键盘、减少动态效果、确认/拒绝、取消、错误重试、账号切换及 Pages 离线查看。真实模型的工具协议、跨域配置和回答质量需使用用户配置另行验证，本轮没有调用真实模型或发布服务。

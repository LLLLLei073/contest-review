# 减少滚动的布局调整

用户要求尽量减少滑动，并明确继续实施。延续已确认的清爽训练工作台风格，调整展示密度，不改训练、评分、备份或算法数据。

## 选择与实现

单纯缩小字体会损害阅读；给每个面板增加独立滚动条会增加操作负担。本轮采用紧凑摘要、同类信息并排和可发现的分区入口。

- 全站缩小页头与区块间距，窄屏省略装饰性英文眉题；快捷入口允许并排。
- 统计来源并入页头，AI 操作使用明确的展开入口；四项指标收紧，平板及桌面四列、手机两列。
- 手机掌握度以“雷达图 / 领域明细”切换，桌面并排保留二者。趋势分为重做与题单、错因与算法分布、错因变化；每日题单默认折叠，分区写入 URL，刷新和返回可恢复。
- 设置中三个账号状态并排，当前账号完整内容仍在对应表单可见。学习路径保留下一步与样本摘要，估时、完成条件及证据按需展开。
- 修正底部导航继承桌面内边距导致的内部滚动；共用高度变量，八入口完整显示，复盘固定保存栏随导航高度调整。

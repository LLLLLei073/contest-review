# 整合版 OJ 数据分析 Dashboard（数据总览页）+ 雷达图重写 + 洛谷集成

无新依赖：延续全手写 SVG 图表与既有双端（server / browser）架构。

## A. 洛谷集成（全新，模仿 AtCoder 模式）

**1. 新建 `shared/luogu.ts`**（模板 = `shared/atcoder.ts`）
- zod schema：`luoguUidSchema`（纯数字）、`luoguUserSchema`、`luoguRecordSchema`
- `HttpLuoguClient`：`https://www.luogu.com.cn` + `_contentOnly=1` 参数与 `x-luogu-type: content-only` 头；串行队列 + ≥2500ms 限速 + 3 次重试；方法 `user(uid)`、`records(uid, page)`
- 状态码→verdict 映射（12→AC、6→WA、5→TLE、4→MLE、7→RE、2→CE、其余→PARTIAL/TESTING）
- 难度枚举→估算 rating：入门800 / 普及-1000 / 普及+提高-1200 / 普及+/提高1500 / 提高+/省选-1900 / 省选/NOI-2300 / NOI+2700，暂无→null
- `normalizeLuogu() → CFSubmission`（`source:'luogu'`，index=pid，url 指向洛谷题面）
- `LuoguService`：`bind(uid)`（拉取用户验证+落库 external `luogu:{uid}/user` + settings `luogu-active`）；`start/run` 同步 job（分页拉 record/list，增量以已存最大 record id 截停，job 复用 SyncJob 形态）
- 已知限制（注释注明）：非官方接口、仅能取到较近一段提交记录

**2. `shared/domain.ts`**：`problemSchema.source` 与 `CFSubmission.source` 加 `'luogu'`；`Settings` 加 `activeLuogu?`、`luoguUsers?`

**3. `shared/core-store.ts`**：
- `luoguProfile(uid)='lg~'+uid`、`luoguKey(pid)='luogu:'+pid`、`luoguUsers()`（LIKE 'lg~%'）、`activeLuogu()`、`activateLuogu()`
- `profileForKey` 路由 `luogu:` 前缀；`setSetting` epoch 失效键加 `'luogu-active'`
- `ingestLuogu()`（照 `ingestAtcoder`：归一化入库 problems/submissions/reviews）
- `combinedProblems()`/`combinedStatistics()` 纳入 luogu profile，source 扩为 `'all'|'cf'|'atcoder'|'luogu'`
- backup/restore 补 `activeLuogu`（profiles 通配 `lg~%` 天然覆盖，核对 `shared/backup-summary.ts` 与 restore ~2209 行）

**4. API 双端路由**：`server/app.ts` 与 `src/browser/api.ts` 各加 `GET/POST /api/luogu/binding`、`GET/POST /api/luogu/sync`；浏览器模式下 fetch 失败返回「洛谷同步仅本地模式可用」（用户已确认此取舍）

## B. Insights 聚合端点

**5. 新建 `shared/insights.ts`**：`buildInsights(store)` 一次性返回——bindings（三平台 handle/rating/通过数/最近同步）、totals（分平台 solved/submissions、活跃天数）、ratings（CF rating 链取自 contests 行、AtCoder 取 external history）、mastery（all/cf/atcoder/luogu 四组 8 轴）、difficulty 分桶直方图、近 12 个月分平台 activity。**6.** `GET /api/insights` 双端注册。

## C. 雷达图重写（组件化 + 多系列）

**7. 新建 `src/components/charts/RadarChart.vue`**：props `axes`/`series[{name,color,values}]`/`max`；N 轴环+轴线+外置标签、每系列半透明多边形+描边+顶点圆点+title 提示、图例；沿用 `useSpringValues` 动画；首个系列多边形保留 `radar-value` class 与 `data-target-scores` 属性 → 现有 e2e（motion/compact-layout/atcoder spec）不动即过。**8.** `Statistics.vue` 内联 SVG 替换为该组件（单系列随 source 切换），删除内联计算函数。

## D. 数据总览页（单页承载全部数据）

**9.** `src/main.ts` 加 `/insights`（懒加载）；`src/navigation.ts` 分析组加「数据总览」（lucide `Radar` 图标）；App.vue 面包屑补标签。
**10. 新建 `src/pages/Insights.vue`**（scoped 样式 + var(--) tokens）：
- **绑定卡片行**：CF/AtCoder/洛谷三卡。已绑：handle/rating/通过数/最近同步 + 「同步」按钮（轮询 2s）；未绑：内联绑定表单（CF/AtCoder 用户名、洛谷 UID）；浏览器模式洛谷卡显示「仅本地模式可用」
- **指标行**：总通过/总提交/活跃天数/CF·AtCoder rating/洛谷通过
- **Rating 走势**：手写 SVG 双折线（CF/AtCoder 双色+图例）
- **能力雷达**：RadarChart，全部/CF/AtCoder/洛谷系列可勾选叠加
- **难度分布**、**近 12 个月活跃**：分平台堆叠柱（沿用 Statistics 的 div 高度堆叠柱模式）
- 未绑定引导空态；390px 响应式 + reduced-motion 安全
**11.** Settings 账号连接：`AccountConnections` 子开关加 'luogu'，UID 绑定表单 + 同步状态（对齐 AtCoder 卡交互）

## 风险
- 洛谷非官方接口可能变动/反爬：保守限速+重试+明确报错；仅能同步较近提交，历史深度受限
- 洛谷失败题将自动进入复习队列（与 AtCoder 行为一致，属整合预期）
- 难度→rating 为估算值，仅用于分布展示

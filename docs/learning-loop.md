# AI 学习闭环

实现入口：导航「知识中心」、题目详情「学习闭环」、比赛报告「AI 教练」。本地 SQLite 与 Pages 使用相同的共享业务逻辑。

## 功能与使用

1. 在题目详情保存复盘或完成 AI Code Review，然后生成经验卡草稿。
2. 到知识中心编辑内容、核对关联知识点并确认。未经确认的 AI 草稿不参与 RAG 或图谱；资料来源改变后，相关卡片停止检索，历史引用标记失效。手工编辑过的卡片不会被刷新草稿覆盖。
3. RAG 使用本地中文切词、算法别名、标题与正文评分检索。回答的引用必须来自本次实际检索；无匹配资料时显示缺口，通用解释单独显示。内置 14 张算法卡覆盖八个领域，无 Embedding 服务或外站自动采集。
4. 图谱显示算法前置、题目涉及的知识、错因与确认后的经验关联；可筛选领域、展开邻接关系或查看完整列表。样本与独立完成证据不能替代已有掌握判定。
5. 学情诊断支持近 30 天与全部历史，附证据编号、行动建议和样本不足提示。用时只来自手动记录，不把提交间隔视为思考时间。
6. 分级提示按方向、观察、算法思路、题解顺序请求。同一练习会话使用提示后，独立评价会转换为借助提示；后续独立重做仍可正常推进。
7. 训练 Agent 在已选周目标与已保存题库范围内调整次日新知题。自动开关默认关闭；开启后在首页、同步检查与训练反馈变化时触发，同一输入自动去重。已安排的迁移任务需保留，当天题单及每栏五题上限保持稳定。版本可撤回，失败沿用规则题单。撤回的相同输入不会自动重应用；失败的手动生成可重试。
8. 对拍支持 C++17 / Python 3，下载 ZIP 包后审阅并在本机执行，再导入 `report.json`。脚本含待测代码、暴力参考解、确定性生成器及 Node.js 驱动。支持种子、轮数、超时、编译器与 Python 路径；参考解允许更长运行时间。输出按去除首尾空白后的文本比较，不支持交互、浮点容差或多解判定。测试通过不证明算法正确；应用明确显示报告来自用户本机。
9. AI 比赛教练基于已有报告与笔记提供策略，作为后续 Agent 输入。CF/AtCoder 仅使用可用证据；XCPC 教练按绑定选手隔离，只能分析队伍和全场统计。
10. 迁移任务选择未提交、未分配且知识点相关的 CF 题，优先不同标签组合与相近难度，占次日新知名额。独立完成需同步到任务建立后的 AC；结果只记录一次，更新诊断和图谱证据，不直接修改原题掌握阶段。

## 共享接口

本地端路径前缀 `/api/learning/`；浏览器适配器使用同名操作。

| 方法 | 操作 | 用途 |
|---|---|---|
| GET | state / graph | 知识、记录、来源状态与派生图谱 |
| POST | search / ask | 检索或基于引用回答 |
| POST | draft / card / delete | 经验卡生成、编辑确认及记录删除 |
| POST | diagnose / hint | 证据诊断及当前等级提示 |
| POST | preferences / agent / revert | 自动开关、次日计划与版本撤回 |
| POST | bundle / files / report | 对拍包生成、下载内容及报告导入 |
| POST | transfer / transfer-result | 迁移推荐与结果记录 |
| POST | coach | 比赛策略分析 |

数据使用 `external` 中的来源账号或训练账号组合分区，XCPC 教练单独按选手保存。索引及图谱按资料派生，无独立外部存储。AI 密钥不进入知识索引或问答上下文。数据库本身沿用现有结构，备份升级 v8，继续读取 v1–v7，并校验新增记录与旧 AI 留档的结构、账号和关联。切换账号或恢复时增加会话代数，拒绝迟到结果，即使切回原账号也不会接收旧响应。

## 验证

- `npm run check`、`npm test`：共享规则、引用、来源失效、账号隔离、提示评价、计划去重/撤回、备份兼容等。
- 设置 `LEARNING_TEST_PYTHON` 为 Python 3 路径后运行 `npm test`：额外执行 C++/Python 下载脚本的正确、差异、崩溃与超时样例，需要本机 `g++`。
- `npm run build`、`npm run build:pages`：两种构建及离线壳。
- `npm run test:e2e`、`npm run test:pages`：原有流程与新增学习闭环；固定 AI 响应仅用于测试。
- `node --import tsx scripts/verify-learning-live.ts [数据库路径]`：只读获取本地 AI 配置，生成数据仅存内存，验证真实 RAG、提示、诊断、Agent 和对拍包格式，不输出密钥。没有配置时报告 `UNAVAILABLE`，不能视为真实模型通过。

不包含发布或线上验收，也不保证用户设备上的编译器配置。应用关闭后不会后台生成计划。

2026-10-08 验证结果：类型检查、89 项单元测试（包含本机 C++/Python 对拍）、两种构建通过；本地全量浏览器测试 16 项通过，Pages 16 项通过、3 项按原配置跳过。收尾改动的两端学习闭环、报告导入、ZIP CRC 与 390px 布局复验通过。真实模型验证报告 `UNAVAILABLE`：当前本地数据库没有 AI 配置；模型质量及真实接口端到端仍待配置后验收。未提交或发布。

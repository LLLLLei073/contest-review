# AI 配置与模型选择

在「设置与数据 → AI 助手」填写 OpenAI 兼容接口的 Base URL 和 API 密钥，停止输入约 650 毫秒后自动获取模型列表。选择可用模型，再点击保存配置。获取列表不保存密钥或配置，不自动选择、覆盖已填写的模型。

模型列表使用 [OpenAI 模型列表接口](https://developers.openai.com/api/reference/resources/models/methods/list)的 `GET <Base URL>/models` 与 `data[].id` 格式，使用 Bearer 密钥认证。重复、空白或无效模型项会被过滤；下拉框显示模型 ID。Base URL 应与聊天接口所用基础地址相同，例如 `https://api.example.com/v1`，不要填写 `/chat/completions` 完整地址。

界面提供局部加载、错误、刷新与重试状态。服务不支持模型列表、返回空列表、网络失败或浏览器跨域受限时，可以手动填写模型名称后保存；无密钥的本地服务可点击刷新模型列表。请求在 15 秒后超时，切换地址或密钥后迟到结果不会覆盖新列表。

重新打开配置时，页面继续使用掩码显示已保存密钥；获取模型时仅在地址未改变的情况下复用真实密钥。地址更改后需重新输入密钥，避免将旧地址密钥自动发给新地址。真实密钥不放入查询字符串、不返回给页面，不显示服务原始错误内容。配置仍只在用户点击保存时持久化，两端数据库和备份格式保持兼容。

本地版和 Pages 共用模型获取及结果处理。Pages 由浏览器直接请求，供应商需允许站点跨域访问。返回的模型列表不代表每种模型都支持聊天，请选用可接受当前 OpenAI 兼容聊天请求的模型。

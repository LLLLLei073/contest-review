# 知识中心完善验收

日期：2026-10-25。

## 已实现

- 14 个稳定知识点 ID，覆盖原有八个领域。每个知识点提供摘要、适用信号、解题步骤、易错点、手算自检与答案；关键算法附资料链接，正文随应用打包。
- 知识与个人经验使用同一查询规范：NFKC、大小写和空白归一化，多词组合匹配。经验的关联知识标题、领域、英文别名和标签均可参与筛选与资料检索。
- 原始复盘及已确认、来源有效的经验进入资料检索；草稿和失效卡只在个人经验库中供查阅与修订。
- 目录内切换保留查询和领域；跨来源定位不在当前筛选内的知识点时重置查询与领域以显示目标。查询修改会立即清除旧检索结果，并取消迟到响应的展示。
- 阅读页连接先修知识、后续知识、个人经验、相关题目、连战、问答与学习路径。
- 经验来源深链能从图谱切回编辑器，支持 A→B→A 暂存编辑。暂存限当前页面，离开页面前仍需保存。
- 保存使用提交快照；较晚响应不会关闭其他卡片的编辑器，也不会清除提交之后继续输入的内容。账号切换清除页面暂存与旧结果。
- 加载、失败重试、无匹配、来源失效及无效知识 / 经验 ID 均有可见提示。

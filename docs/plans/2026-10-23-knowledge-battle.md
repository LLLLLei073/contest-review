# 知识点连战实施与验收

用户已确认：第一版支持 Codeforces，同知识点连续选题；个人 AC 后直接换题，独立评价后按 1.1～1.5 倍递增奖励，同时提升统计掌握度与 BKT 学习转移率。暂停与刷新保留进度，跳过、明确失败或提示重置连续次数。

## 实现

- `shared/battle-domain.ts`：会话、题目、版本、AC 引用校验和按出题顺序重算的奖励规则。未评价的前序题目阻止后续奖励提前结算。
- `shared/battle-service.ts`：按账号隔离、每账号一个进行中会话；真实题库匹配知识点标签和个人难度，排除提交过、忽略、本轮已出现和今日安排题目；题源不足暂停，不静默换知识点。
- 服务端和浏览器 API 复用同一服务。所有会话操作携带账号、版本和操作标识；异步查询后再次检查账号、恢复代次和版本。无变化的轮询不增长会话历史。
- 连战页面提供原题入口、自动检查、补评、暂停、继续、跳过、失败、结束、难度调整、刷新题库和历史场次。当前题优先，历史默认折叠并逐批展开。入口在今日训练、知识卡片和学习路径。
- 每个真实个人 AC 只计一份学习事实。普通评价与连战引用同一事实时合并；多标签题只归入选择的知识点。已记录提示不被手动独立声明覆盖。
- 统计贡献为 `70 + 15 × 倍率`；BKT 只将该次独立观察的学习转移率从 `0.05` 变为 `0.05 × 倍率`。猜测率、失误率和至少三道不同题目的先修验证要求不变。参数为未校准的产品奖励规则。
- v12 备份保存会话和原始证据，不存派生奖励；兼容 v1～v11。恢复前校验账号、题目、AC、时间顺序、重复引用和进行中会话唯一性。

## 验证范围

- 规则与接口：同知识点与排除条件，旧 AC/团队提交/其他账号不推进，连续倍率封顶、补评修正、重复操作、过期版本、网络失败、账号隔离和备份原子恢复。
- 学习结果：统计评分和 BKT 都获得加成，辅助完成不加成，同一次 AC 不重复入账，先修门槛保留。
- 浏览器：隔离账号与内存生成备份，验证自动换题、补评、暂停保存后刷新、历史修改、题库耗尽及难度调整；1440、503、390 像素下无横向溢出，主要操作保持首屏可达。
- 测试不使用实际学习数据库，不向 Codeforces 提交代码。网络行为用固定提交记录验证，真实平台可用性取决于 Codeforces API。

## 兼容说明

页面关闭时不后台轮询；返回连战页后继续检查。Pages 使用现有单写入标签页锁，服务端使用会话版本防止并发推进。备份恢复后派生学习状态重新计算。现有普通训练和复习的独立评价限制保持不变。

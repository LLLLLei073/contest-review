# 训练工作台与学习算法

本轮将原有功能整理为八个主入口、十个页面，默认明亮主题，可切换深色。导航中的快捷操作支持 Ctrl/Cmd + K；题目筛选、比赛筛选、页面分区保存在链接中。原来的成长装备、配色、会话和历史笔记继续保留。

## 从今日任务到未来计划

今日训练首先提示下一步：待评价、待写复盘、逾期复习、其他复习、新知。提示直接来自当天题单，不另建任务。今天的题单保持稳定。

在「今日训练 → 学习路径」选择目标知识点和每日时间，保存偏好后预览未来计划。预览显示题目、估时、推荐原因、约束和算法版本。可以换题重新校验、确认采用或撤回到变更前安排。新一周仍需明确选择周目标。预算不足时显示缺口，不放宽必须任务与目标约束。

- 知识状态按账号、证据指纹、算法参数及知识图版本缓存；证据变化、账号切换和备份恢复后重新计算，缓存不进入备份，也不覆盖原始评价。
- 知识追踪使用 BKT：初始 0.2、学习 0.05、猜测 0.2、失误 0.1。这些是未校准的工程参数，少于三道不同题目不展示确定的掌握判断。辅助完成、混合技能无法归因及未来记录不作为独立正确证据。
- 学习路径求完整先修闭包，再按目标、未验证程度、解锁关系和参考练习负担作拓扑排序。多前置必须全部保留；图异常时停止自动推荐，仍可打开知识内容。至少三道不同题目的可核验独立完成才标记已验证，不由概率阈值决定。
- 预算选题使用以五分钟为单位向上取整的动态规划；复习、新知各最多五题，并保留目标配额及必须任务。候选池有上限且优先保留约束所需候选。估时来自可用独立练习记录的中位数，样本不足时采用复习 20 分钟、新知 35 分钟的参考值。
- 推荐效用包括知识缺口、目标、路径、后继解锁、领域覆盖和挑战度。权重是可解释的工程策略，没有宣称为经过学习效果验证的最优参数。

后续观察区显示采用计划后的评价、可核验独立完成、提示使用和有效用时。缺少完整用时不计算每小时完成率。迁移与逾期数据是当前账号整体状况，不能据此断言新算法带来因果改善。

离线回放示例：

```powershell
node --import tsx scripts/evaluate-planner.ts --backup snapshot.json --as-of 2026-10-14T04:00:00.000Z --budget 90 --output report.json
```

回放按历史时间截断，晚于截断点的备份或目录不能作为可比历史快照。示例 [合成数据报告](verification/planner-synthetic-report.json) 只验证口径与约束，不是用户学习效果报告。

## ReAct 引导复盘

题目详情、比赛报告及对应星澪会话可开始引导复盘，依次经过定位、回想、查证、验证、沉淀、迁移。每一步读取当前记录、调用工具、观察结果，再保存一个等待用户回答的检查点。页面区分工具记录、用户报告与待验证假设，不展示模型内部推理。

引导共享原有模型配置、工具、提案确认与停止功能。每次最多六次模型调用、十二次工具调用及三分钟总时限；相同工具参数复用本轮结果。没有工具能力、失败或中断时保留检查点，可以继续或使用直接工具。生成笔记和修改计划仍需确认；完成引导不自动获得独立完成证据或提升掌握度。

刷新会恢复阶段与回答。切换账号拒绝迟到响应。恢复备份后执行中的工作流转为暂停，未执行提案失效，重新读取证据后由用户继续。

## 数据、设置与使用边界

备份格式为 v11，接受 v1–v11。恢复前先展示版本、账号和记录概要，完整校验通过后才替换数据并保存恢复前备份。旧备份没有算法偏好或工作流时保持空状态，不补造历史。

AI 连接测试使用当前填写的配置，测试成功不会自动保存。修改接口地址后必须重新填写密钥，不能将旧地址的掩码密钥发送给新地址。配置、模型发现和保存仍分别可用。

本地版保存至 SQLite；Pages 版保存至当前站点路径的 IndexedDB。已缓存页面和记录可离线使用，同步、模型调用需要网络。多标签页占用时关闭其他工作台标签再刷新；清理浏览器数据前导出备份。

固定模型夹具可以验证 ReAct 的真实工具循环，但不证明任意真实模型服务兼容或教学有效。浏览器手机视口检查也不等同于真实手机验收。提交、推送和公网发布不属于本次本地重构。

受限 Windows 环境若 Vite 在 `realpath src/main.ts` 报 EPERM，可在当前终端设置 `$env:VITE_PRESERVE_SYMLINKS='1'` 后构建。此项仅跳过构建器的符号链接规范化，不扩大文件权限；普通环境默认关闭。使用符号链接管理依赖的工程应先核对模块去重行为。本项目使用普通 npm 依赖目录。

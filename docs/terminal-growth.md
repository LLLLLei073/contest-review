# 二次元终端与成长收藏

全站使用深蓝终端与可切换的青色、金色、珊瑚配色。首页呈现学习伙伴、等级和近期成就，`/growth` 展示收藏、成就及分页经验依据。手机首页使用头像，收藏页保留完整角色展示；支持键盘操作与减少动态效果。

## 成长依据

- 从当前选中的 CF / AtCoder 账号记录分别计算，再汇总；XCPC 比赛成绩不转换为解题经验。
- 已导入记录中的首次 AC 每题 20 EXP；后续独立重做 30 EXP，借助提示 10 EXP，失败 0 EXP。
- 同账号、同题、同北京时间日期只取最高重做奖励；首次 AC 当日不叠加重做奖励。独立重做需有当天 AC 依据，提示记录会降级独立奖励。
- 首次有效复盘 15 EXP，需有效内容和可靠的 `firstReflectionAt`。今后保存有效复盘时记录首次时间；旧记录没有时间时不推测补奖。
- Lv.n 的累计门槛为 `50 × n × (n−1)`。Lv.3 / Lv.5 分别解锁星轨领航 / 新星探索。外观和配色可独立装备。
- 等级表示投入，不能代替算法掌握度。删除或恢复学习记录后，成长重新计算；装备不足解锁条件时显示基础收藏。

## 接口与保存

本地服务使用 `/api` 前缀，浏览器模式通过相同共享规则处理：

- `GET /growth/summary`：等级、经验、计数、成就、装备、通知摘要与账号分区。
- `GET /growth/history?page=1&pageSize=20`：稳定排序的经验记录；每页最多 100 条。
- `PUT /growth/equipment`：`appearance`、`palette`，界面同时提交 `scope` 防止账号切换后误保存。
- `PUT /growth/notice`：提交摘要 `revision`，确认已读；版本包含账号分区，旧摘要不能确认新账号的奖励。

不保存可编辑的经验总数。`growth:<CF或->:<ac~AtCoder或->` 仅保存装备及通知已读摘要，包含于现有 v8 备份。恢复校验账号、类型和字段；无成长记录的旧备份可正常恢复并重新计算。历史奖励合并成一次摘要，关闭后记住已读状态。

## 原创素材

工具：内置 imagegen。资源：`src/assets/companion/signal.png`、`orbit.png`、`nova.png`，均保留透明通道，由 Vite 打包并纳入 Pages 离线缓存。

三套素材使用同一原创成年角色“星澪 / ASTRA”，银白短发与侧辫、青色眼睛、温和神情、日系二维游戏插画。生成提示如下（外观变体以基础图为参考）：

1. **SIGNAL**：原创科幻学习伙伴，上半身至大腿构图，深蓝高领机能夹克、象牙白拼接、青色光线与发饰，手持透明青色平板；精细线稿与赛璐璐上色，完整头部和双手，透明背景，无文字、标志或既有角色。
2. **ORBIT**：保留基础角色脸、发型和神情，改为深蓝高领领航制服、象牙白短披肩、金色滚边和星形发饰，手抱金色透明平板；同样构图及画风，透明背景，无场景或文字。
3. **NOVA**：保留基础角色身份，深蓝与象牙白探索夹克、珊瑚红围巾和发饰，一手投影几何星形、一手持小平板；同样构图及画风，透明背景，无场景或文字。

## 验证

`npm test`、`npm run check`、`npm run build`、`npm run build:pages`。

成长浏览器回归：`npx playwright test tests/e2e/growth.spec.ts`；Pages：追加 `--config playwright.pages.config.ts`。覆盖历史汇总、装备、分页、账号隔离、390px / 1440px 页面、失败重试、减少动态效果以及 Pages 离线资源。

# 体验优化与功能整合

六个主入口保持清晰分工：今日训练管理今日题单、次日计划和迁移练习；错题库管理题目与笔记；比赛复盘管理比赛报告、赛后补题及模拟赛；训练统计提供概览、趋势、月度报告与学情诊断；知识中心提供知识、个人经验、算法问答与图谱；设置与数据管理账号、同步、数据健康、备份与 AI 配置。

## 入口与链接

分区使用 URL 的 `view` 参数。设置页以 `platform=cf|atcoder|xcpc` 定位账号，题目详情以 `view=assistant&tool=code|hints|stress|experience|transfer` 定位解题助手。模拟赛分区同样保存 `view`。浏览器前进、后退和刷新恢复选择；显式设置链接优先于会话记忆，非法分区返回默认值。

旧的知识中心 `diagnosis`、`training`、`transfers` 链接分别转到训练统计诊断、今日训练次日计划、今日训练迁移练习；旧统计页 `upsolve`、`health` 链接分别转到比赛补题、设置同步。跳转保留附带的知识卡、经验卡、比赛选择等查询参数。

今日训练提供次日计划状态与待验证迁移数量；比赛复盘显示未完成补题数量。解题助手的五种工具共用代码、语言和题面，分区切换保留输入与笔记草稿。AI 建议填入笔记后仍需用户确认保存；离开未保存的题目或切换比赛继续提示确认。

## 删除与保留依据

删除开屏组件、页面切换状态模块、分区遮罩组件，以及只服务于这些遮罩的样式、计时器、就绪事件与测试。切换不再强制等待 600 毫秒；导航、按钮及图表保留轻量反馈，周目标选择等必要弹窗保留键盘操作和焦点约束。

删除文件为 `src/OpeningIntro.vue`、`src/pageScene.ts`、`src/components/SwitchSurface.vue`。删除前核对静态引用、动态导入、构建与测试入口，删除后再次检索确认业务代码中没有残留引用。清理的六处未使用声明位于 `server/app.ts`、`shared/atcoder.ts`、`shared/core-store.ts`；必要的回调参数以 `_req` 明示保留。没有删除仍被图表、Markdown、数据库、服务端或测试使用的依赖。

次日计划、迁移练习、诊断、补题、数据健康提取为独立功能组件；学习记录请求复用状态处理，重叠请求以最新结果为准，组件卸载后拒绝回写。学习工具及 Markdown 按需加载。未使用声明检查已启用，清理静态检查确认的类型、导入和未使用参数。运行时依赖仍有用途，本轮不删业务依赖。

页面实例按业务路径与账号标识；题号使用解码后的参数，避免 `%3A` 与 `:` 的等价编码触发重建。内容页在账号初始化完成后挂载，导航保持可用；真实请求使用局部加载、错误与重试反馈。

业务仍通过共享服务和两端适配实现。数据库结构、业务 API、备份 v8 及 v1–v7 恢复能力保持兼容。测试使用内存或临时数据库，未操作用户业务数据库。

## 验证

执行 `npm run check`（含未使用声明检查）、`npm test`、`npm run build`、`npm run build:pages`、`npm run test:e2e`、`npm run test:pages`。新增体验用例覆盖旧链接、显式设置定位、非法分区、历史与刷新、笔记及工具上下文保留、离开确认、迟到统计响应，以及 1440px / 390px 各任务入口截图与溢出检查。学习闭环用固定 AI 响应验证，业务回归覆盖提示评价、计划撤回、迁移证据、补题、账号隔离与备份。
